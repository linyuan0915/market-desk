# 数据源与页面重构计划

## 数据源优先级

1. 市场宽度：继续使用大盘云图 skill，不改动。
2. 历史行情：优先 iFinD 同花顺量化 API，接口形态为 `THS_iFinDLogin` + `THS_HistoryQuotes`。
3. iFinD 不可用时：A 股回退 RssCast，港美指数回退 Yahoo/akshare，宏观商品回退 FRED/akshare/公开行情。
4. 实时港股：可评估麦蕊 API，但 licence 必须放环境变量，不写入代码。
5. 美股：Alpaca 适合正式行情和交易接口，但需要 API Key；`robin_stocks` 可作为资讯/热度辅助，不建议作为核心行情源。

当前 macOS 本机已安装 PyPI `iFinDAPI`，但该包只包含 Linux/Windows 动态库，不能在 macOS Python 中直接 import `iFinDPy`。同花顺官方文档显示 macOS 可走 HTTP 接口；如需本机直连 SDK，需要同花顺提供 macOS 版 Python SDK。如部署到 Linux 云服务器，可直接使用当前 iFinD 适配层。

## 页面收敛方向

把当前页面从“功能堆叠”收敛成五个交易工作流：

1. 今日驾驶舱
   - 外围风险、市场宽度、资金主线、宏观压力、自选异动。
   - 每张卡片固定为：结论、证据、今日动作、数据来源。

2. 资金流
   - 合并板块资金热力图、资金主线追踪、北向/主力流向。
   - 新增“买盘质量诊断”：主动买盘强度、委买委卖、成交额放大、资金连续性。

3. 情绪风险
   - 合并市场情绪、涨跌停情绪、极值提醒、历史情绪曲线。
   - 参考用户给的图，做成 Q1-Q6 问答式诊断表，而不是只展示指标。

4. 标的观察
   - 合并自选观察、个股详情、分类池。
   - 每只股票展示：趋势位置、成交额变化、买盘质量、所属主线、风险提示。

5. 数据中心
   - 只作为诊断后台，不放在主交易路径里。
   - 展示数据源状态、覆盖日期、缺失字段、最近更新、失败原因。

## 设计原则

- 不复制东方财富/同花顺的大表格，而是做“结论优先 + 证据链 + 可点开细节”。
- 首页只回答“今天看什么、风险在哪、钱流向哪里、哪些信号变了”。
- 详细模块统一结构：结论卡、关键指标、趋势/热力图、明细表、数据来源。
